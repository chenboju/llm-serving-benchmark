## 八、2×2 交叉分析

這是本輪最主要的產出：把「硬體差異」與「runtime 差異」分離。

| Cell | 4090 llama | 4090 vLLM | Spark llama | Spark vLLM |
|---|---:|---:|---:|---:|
| sharegpt-closed-c01 | 172.97 | | | |
| sharegpt-closed-c16 | 365.17 | | | |
| ruler-perf-b060k-c01 | 9.88 | 14.06 | | |
| 〔其他〕 | | | | |

| 推論 | 讀法 |
|---|---|
| Runtime 效應 | 同一列內比較 llama vs vLLM，各自在自己的硬體上 |
| 硬體效應 | 同一 runtime 跨兩台比較 |
| 交互作用 | vLLM/llama 的比值在兩台是否一致——**不一致才是有趣的發現** |

重點假設：4090 舊版基線顯示 vLLM 在 C16 有約 2.48× 的 decode 優勢，那是在高頻寬離散
顯卡上。GB10 的統一記憶體頻寬低一個量級，continuous batching 的收益是否維持，
由本表回答。**不要事先假定結論**。

引用本表時必須同時看 2.4 節的偏離事項：aarch64 build 與 ARM64 vLLM 映像的差異都會
混進數字裡，不能單獨歸因於硬體。
